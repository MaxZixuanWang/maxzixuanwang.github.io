- **SmartCalendar / 行程智算.** Core team member, October 2025 - April 2026. Co-developed a lightweight, local-first schedule management app with Python and Streamlit. The 1.0 Web prototype uses Ollama to turn natural-language schedule descriptions into structured events, and supports a monthly calendar, event management, reminders, conflict detection, and JSON import/export. The project received a university bronze award and filed a software copyright application. [GitHub](https://github.com/SeanHank/SmartCalendar)
